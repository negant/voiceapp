# Mapa plików zasad — Voice App

Ten plik nie jest nadrzędnym zbiorem zasad. Zasady są rozdzielone tematycznie:

- `architecture.md` — architektura aplikacji, przepływ danych, cykl startu.
- `coding-rules.md` — zasady implementacji, code review i styl zmian.
- `components.md` — Atomic Design (atoms / molecules / organisms).
- `testing.md` — testy jednostkowe (obowiązek przy nowych funkcjach).
- `project-context.md` — kontekst projektu, środowisko, cele i ryzyka.
- `domain-knowledge.md` — wiedza domenowa (audio, voice processing, **status usługi AI**).
- `audio-effects.md` — struktura modułów Basic / Advanced Effects (jeden efekt = jeden folder).
- `credits-backend.md` — pula kredytów testowych (30k instalacji), kontrakt API bootstrap, wyczerpanie puli.

Dodatkowo poza tym katalogiem:
- `AGENTS.md` — instrukcje dla agentów AI (język, git, pliki do aktualizacji).
- `CHANGELOG.md` — historia zmian.
- `PROGRESS.md` — bieżący status prac.

Jeśli aktualizujesz reguły, edytuj bezpośrednio odpowiedni plik tematyczny.
